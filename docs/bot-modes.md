# Режим работы бота: inline-workflow или Web App

Главное меню бота работает в двух режимах, переключаемых **в админке бота**
(а не в `.env`):

| Режим | Поведение |
|-------|-----------|
| `inline` (по умолчанию) | Классический workflow: кнопки «🚀 Купить», «🔐 Моя подписка» и весь процесс покупки внутри чата. |
| `webapp` | Вместо workflow — одна кнопка **«👤 Личный кабинет»** (Telegram `web_app` → `WEB_FRONTEND_URL`). Кнопки «Купить» и «Моя подписка» скрыты; покупки и управление подпиской — в Mini App. |

**Как переключить:**

1. В боте отправьте `/admin` → **⚙️ Система**.
2. Нажмите **🧭 Режим бота: …** — значение переключится между `Inline` и `Web App`,
   главное меню перестроится сразу.

Значение хранится в БД (`site_settings.bot_ui_mode`), применяется ко всем
пользователям и переживает рестарты. В режиме `webapp` устаревшие inline-кнопки из
старых сообщений отвечают подсказкой открыть Личный кабинет.

> Кнопка «Личный кабинет» использует `WEB_FRONTEND_URL` — это должен быть
> публичный HTTPS-домен фронтенда (Telegram требует HTTPS для `web_app`).

> Режим `webapp` тесно связан с [Telegram Mini App](authentication.md#telegram-mini-app-личный-кабинет-внутри-telegram):
> кнопка «Личный кабинет» открывает кабинет с автологином по `initData`.
